# وثيقة المتطلبات

## 1. نظرة عامة على التطبيق

### 1.1 اسم التطبيق
Vodafone Fakka Premium (نظام إدارة باقات فودافون ريد بيزنس VIP وأتمتة باقات اتصالات VIP المؤمن)

### 1.2 المالك والمطور
Nader Akram

### 1.3 الوصف
منصة ويب متكاملة لإدارة خطوط فودافون ريد بيزنس ونظام أتمتة باقات اتصالات حكاية عيلة وإشعارات WhatsApp Business، مبنية وفق معمارية أمنية سحابية تعتمد على التحقق الخلفي الكامل (Zero-Trust) والأتمتة السحابية المستقلة في الخادم (Server-Side Cloud Automation). يتيح النظام للمالك التحكم الشامل وإدارة صلاحيات المفوضين بدقة، مع عزل تام للجلسات ومنع استخدام الشبكات الافتراضية الخاصة (VPN)، وتوفير حزمة أوامر سريعة لصيانة وإدارة الخطوط.

## 2. المستخدمون وسيناريوهات الاستخدام

### 2.1 المستخدمون المستهدفون
- المالك العام (Owner): التحكم الكامل بالمنظومة، إدارة جميع الجلسات والتحكم بها، تحديد سقوف الباقات والفواصل الزمنية للمفوضين، ومراقبة السجلات الفورية والتقارير.
- المستخدم المصرح له بقسم VIP: تشغيل وإدارة الجلسات الخاصة به فقط ضمن الحدود القصوى المصرح بها من المالك، ومتابعة السجلات المنقاة وأوامر التشغيل المسموحة.
- مستخدمو النظام والعملاء العاديون: استخدام خدمات فودافون العامة دون إمكانية الوصول إلى قسم VIP.

### 2.2 السيناريوهات الأساسية
- فحص الأمان ومنع VPN: يتحقق النظام عند الدخول من عدم استخدام VPN، مع حظر الوصول وعرض رسالة تنبيه واضحة في حال اكتشاف شبكة افتراضية.
- التحقق من الصلاحيات وتطبيق القيود: عند دخول المستخدم لقسم VIP، يعرض النظام تنبيهاً بالتحقق الخادمي، ثم يفرض القيود المحددة (مثل سقف الباقات 50K أو 100K والفواصل الزمنية).
- إدارة الجلسات المعزولة: ينشئ المستخدم جلساته وتظهر له فقط، بينما تظهر للمالك كافة جلسات النظام موسومة ببيانات منشئها، مع استمرار تنفيذ دورات الأتمتة على السيرفر حتى عند انقطاع الاتصال أو إغلاق التطبيق.
- تنفيذ الأوامر السريعة: تشغيل أوامر الصيانة وتحديث الباقات وفك التعليق للخطوط من خلال لوحة التحكم.

## 3. هيكل الصفحات والوظائف

### 3.1 هيكل الصفحات

```
Vodafone Fakka Premium
├── بوابة تسجيل الدخول (مع نظام كشف وحظر الـ VPN)
├── لوحة تحكم المالك (Owner Admin Panel)
│   ├── إدارة قسم باقات اتصالات VIP
│   │   ├── قائمة المستخدمين المفوضين والبحث المتقدم وضبط الصلاحيات
│   │   ├── محطة إدارة الجلسات العامة (عرض جلسات المالك وجلسات المفوضين مع وسم المستخدم)
│   │   ├── مركز التحكم بالأوامر السريعة الشاملة
│   │   ├── شاشة السجلات الحية الكاملة والرقابة اللحظية
│   │   └── صفحة تدقيق وسجل تفاصيل المستخدم
│   ├── قسم فودافون ريد بيزنس VIP
│   └── قسم إدارة WhatsApp Business
├── واجهة قسم اتصالات VIP للمفوضين (المسار: /vip)
│   ├── مؤشر التحقق من الصلاحيات الخادمية والحصة المتبقية
│   ├── محطة إدارة الجلسات الخاصة (مع حجب جلسات المالك تماماً)
│   ├── لوحة الجلسة النشطة والأتمتة السحابية المقيدة
│   ├── حزمة الأوامر السريعة المصرح بها
│   └── شاشة السجلات الحية المنقاة
└── بوابة خدمات فودافون والعملاء العامة
```

### 3.2 نظام التحقق والأمان وكشف الـ VPN
- فحص ومنع VPN الإجباري:
  - فحص نوع الاتصال ومنع تسجيل الدخول أو فتح التطبيق عند رصد استخدام VPN أو Proxy.
  - إظهار رسالة تنبيه للمستخدم: 「يرجى إغلاق الـ VPN والمحاولة مرة أخرى」 عند محاولة الاتصال عبر شبكة غير مصرح بها.
- التحقق الأمني الخادمي لدخول قسم VIP:
  - إظهار رسالة تحقق واضحة عند فتح القسم: 「جاري التحقق من صلاحيات المستخدم على السيرفر」.
  - جلب القيود الصارمة وتطبيقها خادمياً قبل تمكين أي عنصر تحكم.

### 3.3 عزل وإدارة الجلسات والأتمتة السحابية
- نظام العزل الصارم للجلسات:
  - منع ظهور أي جلسة أنشأها المالك في واجهة المستخدمين المفوضين نهائياً.
  - حصر ظهور جلسات المستخدم المفوض في واجهته الشخصية فقط.
  - إتاحة رؤية وإدارة جميع جلسات النظام للمالك مع تمييزها بوسم واضح يتضمن اسم المستخدم والبريد الإلكتروني لمنشئ الجلسة.
- صلاحيات التحكم العليا للمالك:
  - تعديل باقات وسقوف الجلسات، تعديل الفواصل الزمنية، وإنهاء أو إيقاف أي جلسة للمالك أو المفوضين في أي وقت.
- الأتمتة السحابية المستمرة (Server-Side Cloud Automation):
  - استمرار تشغيل دورات الأتمتة والجلسات على الخادم بشكل مستقل ومستمر حتى في حال إغلاق المتصفح أو التطبيق أو انقطاع الاتصال أو إغلاق الجهاز حتى اكتمال الدورة المحددة.

### 3.4 وحدة الأوامر السريعة
- توفير واجهة تشغيل وصيانة فورية للأوامر التالية وفق الصلاحيات المحددة:
  - أمر تجديد باقة الأونر.
  - أمر إخراج خط الفرد.
  - أمر فحص حالة الخط بالسيرفر.
  - أمر تحويل لنظام أهلاً أقوى كارت.
  - أمر تحويل خط الفرد لباقة 270.
  - أمر فك تعليق خط الفرد.

## 4. قواعد العمل والمنطق الأساسي

### 4.1 ضوابط الوصول والقيود الخادمية
1. يمنع الخادم تماماً أي اتصال قادم من شبكات VPN أو عناوين خوادم الوكيل (Proxies).
2. يتم فرض السقف الأقصى للباقات المحدد لكل مستخدم (مثل 50K أو 100K) من جانب الخادم ويُرفض أي طلب يتجاوز الحد.
3. يتم فرض وتثبيت الفواصل الزمنية الإجبارية (Cooldown) من خلال الخادم ولا يمكن تجاوزها عبر الواجهة.
4. لا تظهر جلسات المالك في أي استجابة برمجية موجهة للمستخدمين المفوضين لضمان العزل الكامل للبيانات.

### 4.2 تشغيل الأتمتة والأوامر السريعة
5. تدار مهام الأتمتة كعمليات خلفية سحابية مستقلة على السيرفر تكتمل ذاتياً بغض النظر عن حالة اتصال العميل.
6. تُنفذ الأوامر السريعة مباشرة مع إرجاع تقرير فوري بحالة التنفيذ وتحديث سجل العمليات.
7. تخصم التفعيلات من الحصة اليومية للمستخدم فقط بعد نجاح المعالجة الكاملة على السيرفر.

## 5. الحالات الاستثنائية والحدود

| الحالة | السلوك المتوقع |
|---|---|
| محاولة فتح التطبيق أثناء تشغيل VPN | منع الوصول وعرض رسالة 「يرجى إغلاق الـ VPN والمحاولة مرة أخرى」 |
| محاولة مستخدم اختيار باقة تتجاوز سقفه المسموح | حظر الاختيار خادمياً ورفض الأمر وتسجيل المحاولة في سجل المالك |
| انقطاع الاتصال أو إغلاق المتصفح أثناء تشغيل جلسة | استمرار السيرفر في تنفيذ دورة الأتمتة حتى اكتمالها دون توقف |
| محاولة وصول مستخدم لبيانات جلسات المالك | حجب الاستجابة بالكامل من الخادم ومنع استعراض البيانات |
| تعليق خط الفرد أثناء تنفيذ العمليات | إمكانية إطلاق أمر فك تعليق خط الفرد لإعادة تهيئة الخط ومتابعة التشغيل |

## 6. معايير القبول

1. نجاح حظر الدخول عند تشغيل VPN مع إظهار رسالة التنبيه المحددة بدقة.
2. إتمام التحقق الخادمي عند دخول قسم VIP مع عرض رسالة التحقق وتطبيق قيود الباقات والفواصل الزمنية بدقة.
3. تطبيق العزل التام بحيث لا تظهر جلسات المالك للمفوضين، وتظهر جلسات المفوضين للمالك مع وسم الاسم والبريد الإلكتروني.
4. استمرار عمل دورات الأتمتة السحابية على السيرفر بنجاح حتى عند إغلاق التطبيق أو انقطاع الاتصال.
5. تشغيل واختبار حزمة الأوامر السريعة الستة (تجديد باقة الأونر، إخراج الفرد، فحص الحالة، تحويل لأهلاً أقوى كارت، تحويل لباقة 270، وفك تعليق الفرد) والتأكد من استجابتها الكاملة.
6. امتلاك المالك صلاحية التحكم الشامل والإنهاء والتعديل لجميع الجلسات والقيود في النظام.
