Vodafone Fakka Premium (نظام إدارة باقات فودافون ريد بيزنس VIP، قسم أتمتة اتصالات VIP، وإدارة إشعارات واتساب)

## 2. المستخدمون وسيناريوهات الاستخدام

### 2.1 المستخدمون المستهدفون
- المالك المصرح له (Authorized Owner): الوصول الحصري لقسم اتصالات VIP، ضبط بيانات الفرد الافتراضية، إنشاء وإدارة الجلسات، ومتابعة وتشغيل الأتمتة التلقائية.
- مسؤولو النظام (Admin): متابعة طلبات واشتراكات فودافون ريد بيزنس وإشعارات WhatsApp Business.
- التجار والعملاء: متابعة الخطوط والفواتير والتجديدات التابعة لفودافون.

### 2.2 السيناريوهات الأساسية
- التحقق من صلاحيات المالك على مستوى الخادم قبل السماح بالدخول إلى قسم `/vip`.
- حفظ بيانات الفرد (البريد وكلمة المرور) كإعدادات افتراضية مسبقة، واسترجاعها تلقائياً عند فتح نافذة إنشاء جلسة جديدة دون الحاجة لإعادة كتابتها يدوياً.
- إنشاء جلسة جديدة بمجرد إدخال بريد وكلمة مرور الأونر مع إمكانية تعديل بيانات الفرد إن لزم الأمر.
- الجلب الفوري والشامل لبيانات الجلسة النشطة (أرقام الخطوط، الرصيد، النظام الحالي، وحالة ربط الفرد في العائلة) فور فتح الجلسة.
- ربط الفرد بالعائلة بنقرة واحدة مباشرة في حال كان غير مربوط.
- تشغيل الدورة التلقائية بمحددات واضحة (الهدف وزمن الانتظار) مع ضبط النظام تلقائياً إلى 270 أو 180 في حال كان النظام الحالي غير متوافق.
- متابعة خطوات السكريبت عبر شاشة السجلات الحية بشكل مباشر ومستقر.

## 3. هيكل الصفحات والوظائف

### 3.1 هيكل الصفحات

```
├── الصفحة الرئيسية

│   └── بوابة قسم إدارة اتصالات VIP (مقتصرة على المالك المصرح له)
├── قسم اتصالات VIP المبسط (المسار: /vip) [محمي بالخادم]
│   ├── شريط إدارة الجلسات وزر ضبط بيانات الفرد الافتراضية
│   ├── نافذة إنشاء جلسة جديدة (معبأة مسبقاً ببيانات الفرد)

    ├── لوحة المؤشرات التشغيلية
    ├── قواعد الإشعارات التلقائية
    └── سجل الرسائل ومسار الأحداث
```

### 3.2 إدارة الجلسات والبيانات الافتراضية
- شريط الجلسات العلوي:
  - التبديل السريع بين الجلسات المفتوحة.
  - زر إنشاء جلسة جديدة.
  - زر ضبط بيانات الفرد الافتراضية.
- نافذة ضبط بيانات الفرد الافتراضية (Default Child Settings):
  - إدخال وحفظ البريد الإلكتروني وكلمة المرور الافتراضية لحساب الفرد على مستوى النظام.
  - إتاحة التعديل والحفظ في أي وقت.
- نافذة إنشاء جلسة جديدة:
  - حقل اسم الجلسة (اختياري).
  - حقل البريد الإلكتروني للأونر (إلزامي).
  - حقل كلمة مرور الأونر (إلزامي).
  - حقول البريد وكلمة المرور للفرد (معبأة تلقائياً بالقيم الافتراضية مع قابلية التعديل المباشر).
  - تحديد هدف الميكسات وزمن الانتظار بين الدورات.

### 3.3 البطاقة الموحدة الشاملة (Unified Session & Family Card)
- بطاقة رئيسية موحدة في أعلى واجهة الجلسة تستبدل الكروت المتعددة، وتتضمن فور فتح الجلسة:
  - قسم الأونر: البريد الإلكتروني، رقم خط الأونر المستخرج آلياً، النظام الحالي، ورصيد الميكسات الحالي.
  - قسم الفرد: البريد الإلكتروني، رقم خط الفرد المستخرج، ورصيد الميكسات المتاح لديه.
  - مؤشر حالة ربط العائلة: بيان حالة هل الفرد مضاف بالعائلة أم لا.
  - زر الربط السريع: يظهر بوضوح عند عدم ربط الفرد لتنفيذ إرسال الدعوة وقبولها وتأكيدها آلياً بنقرة واحدة.
  - زر تحديث الحالة: لجلب أحدث البيانات والأرصدة من الخادم يدوياً عند الحاجة.

### 3.4 لوحة التحكم المبسطة للدورة التلقائية
- عناصر التحكم الأساسية:
  - تحديد رصيد الميكسات المستهدف (خيارات سريعة أو إدخال يدوي).
  - تحديد زمن الانتظار بين الدورات بالثواني.
  - زر بدء الدورة (Start) وزر الإيقاف (Stop).
- المعالجة الذكية للنظام:
  - فحص نظام الأونر تلقائياً؛ إذا كان النظام مختلفاً عن الباقات المتوافقة (مثل نظام 240 أو غيره)، يقوم النظام تلقائياً بترحيله إلى النظام المتوافق (270 أو 180) دون توقف الدورة.
- شريط التقدم ومؤشرات التشغيل:
  - نسبة الإنجاز نحو الهدف ورقم الدورة الحالية والعد التنازلي لفترة الانتظار.

### 3.5 شاشة السجلات الحية (Live Terminal Logs)
- نافذة متكاملة تعرض أحداث وتنفيذ دوال الخادم بشكل خطي ومباشر ومستقر.
- توثيق تسلسل الأحداث: تسجيل الدخول، استخراج التوكن، التجديد، التحويل، الترحيل الآلي، والاستجابات.
- إخفاء تام لكلمات المرور والبيانات الحساسة من السجلات.

### 3.6 أقسام فودافون ريد بيزنس وإشعارات واتساب
- استمرار عمل قسم فودافون ريد بيزنس وقسم إشعارات WhatsApp Business بكامل كفاءتهما السابقة.

## 4. قواعد العمل والمنطق الأساسي

1. التعبئة التلقائية لبيانات الفرد: عند فتح نافذة إنشاء جلسة جديدة، يتم استدعاء البريد وكلمة المرور المحفوظين مسبقاً في النظام كقيم افتراضية مع السماح بتعديلهما للجلسة الحالية فقط دون التأثير على الإعداد العام إلا في حال تحديث الإعدادات الافتراضية.
2. الاستعلام الفوري عند بدء الجلسة: بمجرد اختيار الجلسة، يقوم الخادم بتسجيل دخول الأونر والفرد واستخراج البيانات والأرصدة والتحقق من قائمة العائلة لعرضها في البطاقة الموحدة.
3. المعالجة الذكية للنظام غير المتوافق: أثناء تشغيل الدورة التلقائية، إذا تم رصد نظام غير الباقتين المعتمدتين (Hekaya 270 أو Hekaya 180)، يتم تشغيل إجراء التحويل التلقائي للنظام المتوافق كخطوة تصحيحية تمهيدية ومتابعة الدورة.
4. تسلسل تنفيذ الدورة التلقائية المبسطة:
   - التحقق من ربط الفرد (والتنبيه في حال عدم الربط).
   - التحقق من مطابقة النظام وتصحيحه إن تطلب الأمر.
   - فحص الرصيد وإيقاف الدورة عند بلوغ الهدف المحدد.
   - تجديد باقة الأونر (تأخير 3 ثوانٍ عند النجاح، أو 15 ثانية عند الفشل وتخطي الخطوات التالية).
   - تحويل الميكسات للفرد المربوط.
   - طلب تغيير النظام ومراقبة الاستجابة كل ثانيتين حتى اعتماد النظام الجديد وظهور الرصيد.
   - استرجاع ميكسات الفرد إلى الأونر.
   - تطبيق فترة الانتظار بين الدورات ثم تكرار العملية.
5. ربط الفرد الآلي: عند الضغط على زر الربط في البطاقة الموحدة، يتم استدعاء أمر إضافة الفرد من حساب الأونر، واستخراج رمز التأكيد وقبوله عبر حساب الفرد تلقائياً وتحديث حالة البطاقة إلى «مربوط».

## 5. الحالات الاستثنائية والحدود

| الحالة | السلوك المتوقع |
|---|---|
| عدم وجود بيانات فرد افتراضية محفوظة | فتح نافذة الجلسة بحقول فارغة للفرد مع إتاحة الحفظ المباشر للإعداد الافتراضي |
| الفرد غير مضاف بالعائلة عند بدء الدورة التلقائية | إيقاف الدورة مؤقتاً، إظهار تنبيه، وإبراز زر الربط السريع في البطاقة الموحدة |
| اكتشاف نظام أونر غير متوافق (مثل نظام 240) | تنفيذ الترحيل التلقائي إلى نظام 270 أو 180 قبل متابعة خطوات الدورة المعتادة |
| فشل تجديد باقة الأونر | تطبيق مهلة 15 ثانية، تسجيل السبب في السجلات، وإعادة المحاولة في الدورة اللاحقة |
| تعثر الاتصال بخدمات الخادم أو معالجة الطلبات | إعادة المحاولة التلقائية مع تسجيل تنبيه تشغيلي واضح في السجلات دون إيقاف الجلسة كلياً |
| بلوغ الهدف المحدد للميكسات | إيقاف الدورة التلقائية، وسم الجلسة كمكتملة، وتحديث نسبة التقدم إلى 100% |

## 6. معايير القبول

1. إتاحة حفظ وتعديل بيانات الفرد الافتراضية وتعبئتها تلقائياً داخل نافذة إنشاء الجلسات الجديدة.
2. عرض واجهة اتصالات VIP عبر بطاقة موحدة شاملة لبيانات الأونر والفرد وحالة الربط دون تشتت أو تعدد في البطاقات المنفصلة.
3. عمل زر الربط السريع في البطاقة الموحدة لربط الفرد وقبول الدعوة بنقرة واحدة وبشكل آلي كامل.
4. معالجة الأنظمة غير المتوافقة تلقائياً وترحيلها إلى النظام الصحيح أثناء تشغيل الدورة التلقائية.
5. نجاح تشغيل وإيقاف الدورة التلقائية ومتابعة نسبة الإنجاز والعداد الزمني بدقة.
6. استقرار شاشة السجلات الحية وعرضها لمخرجات الخادم خطوة بخطوة وبشكل متواصل.
7. الحفاظ على العزل التام بين بيانات وأرصدة وسياقات الجلسات المختلفة.
8. حجب وإخفاء كلمات المرور والبيانات الحساسة من الواجهات وشاشات السجلات.
