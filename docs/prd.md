# وثيقة المتطلبات

## 1. نظرة عامة على التطبيق

### 1.1 اسم التطبيق
Vodafone Fakka Premium

### 1.2 المالك
Nader Akram

### 1.3 الإصدار
v3.0.38

### 1.4 الوصف
منصة ويب احترافية لشحن كروت الفكة مع نظام اشتراكات وأكواد ترخيص، مصممة بواجهة عربية فاخرة وتدعم التكامل المستقبلي مع محرك شحن خارجي. تتضمن مركز شبكات متعدد لعرض خدمات Vodafone وOrange وEtisalat وWE، مع نظام إدارة كروت ديناميكي كامل وتحسينات أداء شاملة. تشمل المرحلة الجديدة إعادة بناء لوحة الإدارة بالكامل بصفحات كاملة احترافية، بالإضافة إلى نظام تقييم الكروت واقتراح التعديلات، ونظام وضع المعاينة Preview Mode، وإعادة بناء قسم عروض واشتراكات فودافون بالكامل، وتحسينات شاملة لقسم خدمات الخطوط والمحافظ (My NTRA) في PHASE 3.

### 1.5 المبادئ الأساسية
- جميع البيانات ديناميكية (الكروت، الأسعار، الوحدات، الحالات)
- لا توجد بيانات ثابتة أو افتراضية
- النظام جاهز للربط مع API خارجي أو Recharge Engine
- تصميم Premium حديث بنمط Dark Luxury UI
- دعم كامل للغة العربية RTL
- Mobile First و Responsive
- Offline-First مع مزامنة ذكية
- منع التكرار في جميع العمليات
- لوحة إدارة احترافية بصفحات كاملة بدون Popup/Modal
- حماية Server-Side لجميع الصلاحيات والاشتراكات
- عدم تخزين passwords أو OTP أو tokens في logs أو frontend

### 1.6 الألوان
- Background: #0B0B14
- Primary: #E60000
- Secondary: #FFFFFF
- Accent: #FF3B3B
- Cards: #151523
- Borders: rgba(255,255,255,0.08)

### 1.7 خصائص التصميم
- Glassmorphism خفيف
- Shadows احترافية
- Animations ناعمة وسريعة
- Glow Effects و Border Animations
- Smooth Transitions
- Skeleton Loading
- Sticky Header و Sticky Action Bar

## 2. المستخدمون وسيناريوهات الاستخدام

### 2.1 المستخدمون المستهدفون
- المستخدمون النهائيون: أفراد يحتاجون لشحن كروت الفكة واستعراض خدمات الشبكات والاشتراك في عروض فودافون والاستعلام عن خطوطهم ومحافظهم عبر My NTRA
- مستخدمو المعاينة Preview Users: أفراد يريدون تجربة التطبيق قبل الاشتراك
- المسؤولون (Admin): إدارة المستخدمين والاشتراكات والأكواد والكروت والإصدارات والميزات ووضع المعاينة
- المسؤولون الرئيسيون (Super Admin): صلاحيات كاملة على النظام

### 2.2 السيناريوهات الأساسية
- تفعيل الاشتراك باستخدام كود تفعيل
- الدخول إلى وضع المعاينة Preview Mode لتجربة التطبيق
- شحن كروت الفكة بشكل متكرر
- استعراض خدمات الشبكات المختلفة
- استعراض عروض فودافون والاشتراك فيها
- إدارة الاشتراكات القادمة
- شحن الرصيد من قسم عروض فودافون
- حفظ الأرقام المفضلة للشحن السريع
- مراجعة سجل العمليات السابقة
- مراجعة الإحصائيات التفصيلية
- تقييم الكروت واقتراح تعديلات على بياناتها
- الاستعلام عن الخطوط والمحافظ المسجلة باسم المستخدم عبر My NTRA الرسمي
- إدارة الاشتراكات والأكواد والكروت (للمسؤولين)
- إدارة الأصول المرئية الديناميكية (للمسؤولين)
- حذف المستخدمين نهائياً (للمسؤولين)
- مراقبة المستخدمين والإصدارات في الوقت الفعلي (للمسؤولين)
- إدارة الميزات والإصدارات بدون تحديث APK (للمسؤولين)
- تنفيذ إجراءات متقدمة على حسابات المستخدمين (للمسؤولين)
- مراجعة تقييمات واقتراحات المستخدمين على الكروت (للمسؤولين)
- إدارة وضع المعاينة Preview Mode (للمسؤولين)

### 3.2 قسم خدمات الخطوط والمحافظ (My NTRA) - PHASE 3

#### 3.2.1 الصفحة الرئيسية للقسم

##### الوظيفة
- عرض بطاقة توضيحية في أعلى الصفحة تحتوي على:
  - أيقونة معلومات واضحة
  - عنوان: خدمة الاستعلام عن الخطوط والمحافظ
  - نص توضيحي: هذه الخدمة مخصصة للاستعلام عن بيانات الخطوط والمحافظ المسجلة باسمك عبر My NTRA الرسمي (الجهاز القومي لتنظيم الاتصالات في مصر)
- عرض بطاقات قصيرة ومضغوطة تحتوي على:
  - بطاقة تسجيل الدخول: أيقونة، عنوان، وصف مختصر، زر الدخول
  - بطاقة إنشاء حساب جديد: أيقونة، عنوان، وصف مختصر، زر إنشاء
- التصميم: Dark Premium UI، RTL، Mobile First، بدون Horizontal Overflow
- زر العودة للصفحة الرئيسية
- لا يتطلب اشتراكاً نشطاً للوصول إلى هذا القسم (خدمة مجانية)

#### 3.2.2 صفحة تسجيل الدخول

##### الوظيفة
- Header: عنوان تسجيل الدخول إلى My NTRA، زر العودة
- عرض وصف واضح: سجّل الدخول باستخدام حسابك الرسمي على My NTRA للوصول إلى بيانات الخطوط والمحافظ المسجلة باسمك
- حقول الإدخال:
  - البريد الإلكتروني أو رقم الهاتف
  - كلمة المرور
- زر تسجيل الدخول
- عرض توضيح أسفل النموذج: ليس لديك حساب على My NTRA؟ يمكنك إنشاء حساب جديد من هنا
- زر إنشاء حساب مميز (بتصميم Secondary Button)
- عند نجاح تسجيل الدخول:
  - حفظ token و deviceId و username في localStorage
  - حفظ الاسم الحقيقي والبريد الإلكتروني القادمين من My NTRA في localStorage
  - الانتقال إلى صفحة إدخال الرقم القومي
- عند فشل تسجيل الدخول:
  - عرض رسالة خطأ واضحة داخل القسم
  - عدم إعادة المستخدم إلى Home
  - إبقاء المستخدم في صفحة تسجيل الدخول
- Loading State أثناء تسجيل الدخول
- Masking لكلمة المرور

#### 3.2.3 صفحة إنشاء الحساب

##### الوظيفة
- Header: عنوان إنشاء حساب My NTRA جديد، زر العودة
- عرض وصف واضح: أنشئ حسابك الرسمي على My NTRA للوصول إلى بيانات الخطوط والمحافظ المسجلة باسمك. هذا الحساب هو حساب My NTRA الرسمي وليس خاصاً بالتطبيق.
- حقول الإدخال:
  - الاسم الكامل
  - البريد الإلكتروني
  - رقم الهاتف
  - كلمة المرور
  - تأكيد كلمة المرور
- زر إنشاء الحساب
- عند نجاح إنشاء الحساب:
  - حفظ token و deviceId و username في localStorage
  - حفظ الاسم الحقيقي والبريد الإلكتروني في localStorage
  - الانتقال إلى صفحة إدخال الرقم القومي
- عند فشل إنشاء الحساب:
  - عرض رسالة خطأ واضحة داخل القسم
  - عدم إعادة المستخدم إلى Home
  - إبقاء المستخدم في صفحة إنشاء الحساب
- Loading State أثناء إنشاء الحساب
- Masking لكلمة المرور

#### 3.2.4 صفحة إدخال الرقم القومي

##### الوظيفة
- Header: عنوان إدخال الرقم القومي، زر العودة
- عرض اسم المستخدم الحقيقي والبريد الإلكتروني القادمين من My NTRA
- حقل إدخال الرقم القومي (14 رقم)
- زر الاستعلام
- عند نجاح الاستعلام:
  - حفظ nationalId في localStorage
  - الانتقال إلى صفحة النتائج
- عند فشل الاستعلام:
  - عرض رسالة خطأ واضحة داخل القسم
  - عدم إعادة المستخدم إلى Home
  - إبقاء المستخدم في صفحة إدخال الرقم القومي
- Loading State أثناء الاستعلام
- Masking للرقم القومي (عرض آخر 4 أرقام فقط)

#### 3.2.5 صفحة النتائج

##### الوظيفة
- Header: عنوان بيانات الخطوط والمحافظ على My NTRA، زر العودة
- عرض بيانات حساب المستخدم:
  - الاسم الحقيقي القادم من My NTRA
  - البريد الإلكتروني القادم من My NTRA
- عرض إحصائيات:
  - عدد المحافظ المسجلة
  - عدد الخطوط المسجلة
- عرض قائمة المحافظ:
  - كل محفظة في Card مضغوط
  - عرض رقم المحفظة مع Masking (عرض آخر 4 أرقام فقط)
  - زر إظهار الرقم الكامل (يتطلب OTP)
- عرض قائمة الخطوط:
  - كل خط في Card مضغوط
  - عرض رقم الخط مع Masking (عرض آخر 4 أرقام فقط)
  - زر إظهار الرقم الكامل (يتطلب OTP)
- زر تسجيل الخروج
- عند الضغط على زر إظهار الرقم الكامل:
  - إرسال OTP إلى رقم الهاتف المسجل
  - الانتقال إلى صفحة OTP
- Loading State أثناء تحميل البيانات
- رسالة لا توجد بيانات متاحة حالياً إذا كانت القائمة فارغة
- التصميم: Cards مضغوطة، Mobile First، بدون Horizontal Overflow

#### 3.2.6 صفحة OTP

##### الوظيفة
- Header: عنوان التحقق من الهوية، زر العودة
- عرض رسالة: تم إرسال رمز التحقق إلى رقم هاتفك المسجل
- حقل إدخال رمز OTP (6 أرقام)
- زر التحقق
- عند نجاح التحقق:
  - عرض الأرقام الكاملة للمحافظ والخطوط
  - العودة إلى صفحة النتائج
- عند فشل التحقق:
  - عرض رسالة خطأ واضحة
  - السماح بإعادة المحاولة
- زر إعادة إرسال OTP
- Loading State أثناء التحقق

## 4. القواعد والمنطق

### 4.1 منطق قسم خدمات الخطوط والمحافظ (My NTRA) - PHASE 3

#### 4.1.1 الوصول إلى القسم
- القسم متاح لجميع المستخدمين بدون اشتراك نشط (خدمة مجانية)
- لا يتطلب Subscription Gate
- يمكن للمستخدمين في Preview Mode الوصول إلى القسم

#### 4.1.2 تسجيل الدخول وإنشاء الحساب
- الحساب هو حساب My NTRA الرسمي وليس خاصاً بالتطبيق
- عند نجاح تسجيل الدخول أو إنشاء الحساب:
  - حفظ token و deviceId و username في localStorage
  - حفظ الاسم الحقيقي (fullName) والبريد الإلكتروني (email) القادمين من My NTRA في localStorage
  - الانتقال إلى صفحة إدخال الرقم القومي
- عند فشل تسجيل الدخول أو إنشاء الحساب:
  - عرض رسالة خطأ واضحة داخل القسم
  - عدم إعادة المستخدم إلى Home
  - إبقاء المستخدم في نفس الصفحة

#### 4.1.3 الاستعلام عن الرقم القومي
- عند نجاح الاستعلام:
  - حفظ nationalId في localStorage
  - الانتقال إلى صفحة النتائج
- عند فشل الاستعلام:
  - عرض رسالة خطأ واضحة داخل القسم
  - عدم إعادة المستخدم إلى Home
  - إبقاء المستخدم في صفحة إدخال الرقم القومي

#### 4.1.4 عرض النتائج
- عرض الاسم الحقيقي والبريد الإلكتروني القادمين من My NTRA
- عرض عدد المحافظ وعدد الخطوط
- عرض قائمة المحافظ والخطوط مع Masking (آخر 4 أرقام فقط)
- زر إظهار الرقم الكامل يتطلب OTP

#### 4.1.5 حماية البيانات
- Masking لجميع الأرقام (المحافظ، الخطوط، الرقم القومي)
- عدم تخزين OTP في localStorage أو Console Logs
- عدم تخزين كلمات المرور في localStorage أو Console Logs
- عدم تخزين tokens في Console Logs
- تشفير جميع البيانات الحساسة

#### 4.1.6 إدارة الحالة والتوجيه
- فحص إدارة الحالة (State Management) لضمان عدم فقدان البيانات
- فحص التوجيه (Routing) لضمان عدم إعادة المستخدم إلى Home عند حدوث خطأ
- فحص إعادة تحميل المكونات (Component Remounting) لضمان عدم فقدان البيانات
- فحص استخدام الذاكرة (Memory Usage) لضمان عدم تجميد الواجهة
- فحص دورة حياة الطلبات (Request Lifecycle) لضمان عدم فقدان الطلبات
- فحص حالات الخطأ (Error States) لضمان عرض رسائل خطأ واضحة
- فحص شروط الاشتراك والتوثيق (Subscription/Auth Conditions) لضمان عدم منع المستخدم من الوصول

#### 4.1.7 دعم الأجهزة الضعيفة
- تقليل إعادة الرسم (Re-renders) غير الضرورية
- تقليل العمليات الثقيلة (Heavy Operations)
- تقليل البيانات الكبيرة في الحالة (Large State Data)
- توفير حالات تحميل (Loading States) بدلاً من تجميد الواجهة
- توفير Skeleton Loading أثناء تحميل البيانات
- تحسين الأداء على الشاشات الصغيرة

#### 4.1.8 الاتصال بـ My NTRA
- الخدمة تتصل مباشرة بـ https://my.tra.gov.eg من الجهاز (Direct Device Relay)
- لا يتم استخدام Proxy أو Backend Relay
- التعامل مع الحجب الجغرافي (Geo-blocking) إذا لزم الأمر

### 4.2 إصلاح زر معاينة التطبيق

#### 4.2.1 المشكلة الحالية
- زر معاينة التطبيق يظهر خطأ: تعذر الدخول إلى وضع المعاينة
- المشكلة قد تكون في:
  - إعدادات البيئة (Environment Settings)
  - التوجيه (Routing)
  - حالة المصادقة (Auth State)
  - متغيرات البيئة (Environment Variables)
  - دالة enter_preview_mode في Supabase

#### 4.2.2 الحل المطلوب
- فحص إعدادات البيئة والتأكد من صحتها
- فحص التوجيه والتأكد من عدم وجود تعارض
- فحص حالة المصادقة والتأكد من عدم منع المستخدم
- فحص متغيرات البيئة والتأكد من صحتها
- فحص دالة enter_preview_mode والتأكد من عدم وجود أخطاء
- إصلاح جدول preview_mode_logs:
  - إضافة قيد فريد (UNIQUE CONSTRAINT) على user_id
  - تحديث دالة enter_preview_mode لاستخدام ON CONFLICT (user_id) DO UPDATE
- اختبار زر معاينة التطبيق والتأكد من عمله بشكل صحيح

### 4.3 منطق Preview Mode (محدث)

#### 4.3.1 الدخول إلى Preview Mode
- عند الضغط على زر معاينة التطبيق في شاشة التفعيل:
  - إنشاء حساب مؤقت للمستخدم (إذا لم يكن موجوداً)
  - تحديث access_mode إلى preview
  - تحديث subscription_status إلى none
  - تسجيل الدخول في جدول preview_mode_logs (مع معالجة ON CONFLICT)
  - الانتقال إلى الصفحة الرئيسية
- إذا فشل الدخول:
  - عرض رسالة خطأ واضحة
  - عدم إعادة المستخدم إلى شاشة التفعيل
  - السماح بإعادة المحاولة

#### 4.3.2 إصلاح جدول preview_mode_logs
- إضافة قيد فريد على user_id:
  ```sql
  ALTER TABLE preview_mode_logs
  ADD CONSTRAINT preview_mode_logs_user_id_key UNIQUE (user_id);
  ```
- تحديث دالة enter_preview_mode:
  ```sql
  INSERT INTO preview_mode_logs (user_id, entered_at)
  VALUES (auth.uid(), NOW())
  ON CONFLICT (user_id) DO UPDATE
  SET entered_at = NOW();
  ```

## 6. معايير القبول

1. المستخدم يفتح قسم خدمات الخطوط والمحافظ
2. المستخدم يشاهد بطاقة توضيحية تشرح أن الخدمة من My NTRA الرسمي
3. المستخدم يضغط على بطاقة تسجيل الدخول
4. المستخدم يشاهد صفحة تسجيل الدخول مع وصف واضح
5. المستخدم يشاهد توضيح: ليس لديك حساب على My NTRA؟ يمكنك إنشاء حساب جديد من هنا
6. المستخدم يضغط على زر إنشاء حساب
7. المستخدم يشاهد صفحة إنشاء الحساب مع وصف واضح
8. المستخدم يدخل بياناته وينشئ حساب My NTRA جديد
9. النظام يحفظ token و deviceId و username و fullName و email في localStorage
10. المستخدم ينتقل إلى صفحة إدخال الرقم القومي
11. المستخدم يشاهد اسمه الحقيقي وبريده الإلكتروني القادمين من My NTRA
12. المستخدم يدخل الرقم القومي ويضغط على زر الاستعلام
13. النظام يحفظ nationalId في localStorage
14. المستخدم ينتقل إلى صفحة النتائج
15. المستخدم يشاهد عنوان: بيانات الخطوط والمحافظ على My NTRA
16. المستخدم يشاهد اسمه الحقيقي وبريده الإلكتروني
17. المستخدم يشاهد عدد المحافظ وعدد الخطوط
18. المستخدم يشاهد قائمة المحافظ مع Masking (آخر 4 أرقام فقط)
19. المستخدم يشاهد قائمة الخطوط مع Masking (آخر 4 أرقام فقط)
20. المستخدم يضغط على زر إظهار الرقم الكامل
21. النظام يرسل OTP إلى رقم الهاتف المسجل
22. المستخدم ينتقل إلى صفحة OTP
23. المستخدم يدخل رمز OTP ويضغط على زر التحقق
24. النظام يتحقق من OTP ويعرض الأرقام الكاملة
25. المستخدم يعود إلى صفحة النتائج ويشاهد الأرقام الكاملة
26. المستخدم يضغط على زر تسجيل الخروج
27. النظام يحذف البيانات من localStorage ويعيد المستخدم إلى الصفحة الرئيسية للقسم
28. المستخدم يضغط على زر معاينة التطبيق في شاشة التفعيل
29. النظام ينشئ حساب مؤقت ويسجل في preview_mode_logs
30. المستخدم ينتقل إلى الصفحة الرئيسية بدون أخطاء
31. المستخدم يفتح قسم خدمات الخطوط والمحافظ في Preview Mode
32. المستخدم يستطيع الوصول إلى جميع صفحات القسم بدون قيود
33. عند حدوث خطأ في أي صفحة: عرض رسالة خطأ واضحة داخل القسم، عدم إعادة المستخدم إلى Home
34. على الأجهزة الضعيفة: عرض Loading State أو Skeleton Loading بدلاً من تجميد الواجهة
35. على الشاشات الصغيرة: عرض Cards مضغوطة بدون Horizontal Overflow
36. Admin يفحص جدول preview_mode_logs ويشاهد سجل دخول المستخدمين إلى Preview Mode
37. Admin يفحص دالة enter_preview_mode ويتأكد من عدم وجود أخطاء ON CONFLICT
