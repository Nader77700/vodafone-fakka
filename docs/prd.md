# وثيقة المتطلبات

## 1. نظرة عامة على التطبيق

### 1.1 اسم التطبيق
Vodafone Fakka Premium

### 1.2 المالك
Nader Akram

### 1.3 الإصدار
v3.1.0

### 1.4 الوصف
منصة ويب متكاملة لشحن كروت الفكة وإدارة اشتراكات وخدمات شبكات الاتصالات، تتضمن استعلامات الخطوط وعروض فودافون الرسمية وبوابة My NTRA. يتضمن الإصدار الجديد قسماً مخصصاً VIP داخل صفحة معلومات الخط (Line Info) لمراقبة وتتبع تحويلات خطوط فودافون إلى أنظمة ريد (Enterprise member control) مع نظام فحص آلي وإشعارات فورية وإدارة صلاحيات متقدمة من لوحة الأدمن.

## 2. المستخدمون وسيناريوهات الاستخدام

### 2.1 المستخدمون المستهدفون
- المستخدمون المصرّح لهم (VIP Users) والمسؤولون: مراقبة حالة تحويل الخطوط إلى نظام ريد واستقبال الإشعارات التلقائية.
- مستخدمو المنصة العاديون: الاستفادة من خدمات الشحن واستعلام الخطوط وفق الصلاحيات الممنوحة.
- مسؤولو النظام (Admin): تفعيل الميزة، إدارة المشتركين المسموح لهم بالوصول إلى قسم VIP، وضبط وتيرة الفحص الدوري.

### 2.2 السيناريوهات الأساسية
- قيام الأدمن بتمكين قسم VIP لمستخدم محدد أو تفعيله للجميع، وضبط فترة الفحص الدوري للأرقام.
- قيام المستخدم بإضافة أرقام هواتف فردية أو مجمعة لمراقبة تحويلها إلى نظام ريد.
- فحص النظام تلقائياً للحالة الحالية لكل خط وتصنيفه (قيد المراقبة / تم التحويل بنجاح / غير مؤهل).
- إرسال إشعار فوري عند تحول أي رقم إلى نظام Enterprise member control وتحديث حالته.
- عرض تفاصيل فحص الخط الفردي أو إعادة فحص جميع الأرقام قيد المراقبة دفعة واحدة.

## 3. هيكل الصفحات والوظائف

### 3.1 هيكل الصفحات

```

├── شاشة البداية والتفعيل
├── الصفحة الرئيسية

│   └── قسم VIP لمراقبة تحويلات خطوط ريد
│       ├── تبويب قيد المراقبة
│       ├── تبويب تم التحويل بنجاح
│       ├── تبويب الأرقام غير المؤهلة
│       └── نافذة تفاصيل الخط المنبثقة

    └── إعدادات قسم مراقبة خطوط ريد VIP
```

### 3.2 لوحة الإدارة: إعدادات قسم VIP لمراقبة خطوط ريد

- مفتاح التفعيل العام: تمكين أو تعطيل قسم VIP لجميع مستخدمي المنصة.
- إدارة صلاحيات المستخدمين: قائمة للبحث عن المستخدمين بالاسم أو رقم الهاتف وتفعيل/تعطيل صلاحية قسم VIP لحسابات محددة.
- ضبط وتيرة الفحص التلقائي: اختيار دورية الفحص الدوري في الخلفية من خيارات محددة (كل ساعتين، 4 ساعات، 6 ساعات، 12 ساعة، 24 ساعة).
- حفظ واسترجاع الإعدادات فورياً وتطبيقها على مهام الفحص في الخلفية.

### 3.3 صفحة معلومات الخط: قسم VIP لمراقبة تحويلات خطوط ريد

- التحقق من الصلاحية: يظهر القسم حصرياً لحساب الأدمن أو المستخدمين الممنوحين صلاحية الوصول من لوحة الإدارة.
- إدخال الأرقام للمراقبة:
  * إمكانية إدخال رقم هاتف فردي أو إضافة أرقام متعددة دفعة واحدة (مفصولة بفاصلة أو سطر جديد).
  * إجراء فحص فوري ومباشر للنظام الحالي لكل رقم مضاف بمجرد تقديمه.
- التبويبات والتصنيف:
  * تبويب قيد المراقبة: يعرض الأرقام التي تقع في نظام RX_14pt_Raya7Balak (ريح بالك 14 قرش) أو قيد انتظار التحويل.
  * تبويب تم التحويل بنجاح: يعرض الأرقام التي تحولت بنجاح إلى نظام Enterprise member control (أنظمة ريد).
  * تبويب الأرقام غير المؤهلة: يعرض الأرقام ذات الأنظمة الأخرى (مثل باقات فليكس) مع رسالة توجيهية للتحويل إلى نظام 14 قرش أولاً.
- بطاقة عرض الرقم:
  * عرض رقم الهاتف.
  * اسم النظام الحالي مع تمييز لوني واضح لنظام ريد ونظام ريح بالك 14 قرش.
  * حالة التحويل (قيد المراقبة / تم التحويل بنجاح وجاهز للتفعيل / غير مؤهل).
  * توقيت الإضافة وتوقيت آخر فحص تم إجراؤه.
  * زر تفاصيل الخط: فتح نافذة منبثقة تعرض بيانات الفحص الشاملة (الرصيد، الباقات، الكروت، وسلفني).
  * زر فحص الآن: تنفيذ فحص فوري مباشر للرقم المحدد وتحديث حالته.
  * زر حذف: إزالة الرقم من قائمة المراقبة.
- زر فحص جميع الأرقام الآن: تنفيذ إعادة فحص فورية لجميع الأرقام المسجلة قيد المراقبة وتحديث نتائجها.

## 4. قواعد العمل والمنطق الأساسي

1. معايير تحديد حالة الخط:
   - النظام المؤهل لبدء المراقبة: RX_14pt_Raya7Balak (ريح بالك 14 قرش).
   - النظام المستهدف للتحويل: Enterprise member control (نظام ريد).
   - أي نظام آخر يعتبر غير مؤهل حتى يتم تحويله لنظام 14 قرش.
2. منطق التحويل والتنبيه:
   - عند اكتشاف تحول النظام إلى Enterprise member control أثناء الفحص الفوري أو الدوري:
     * نقل الرقم فوراً إلى تبويب تم التحويل بنجاح.
     * تحديث حالة الرقم إلى جاهز للتفعيل.
     * إرسال إشعار داخل التطبيق وتنبيه للمتصفح بالنص: تم تحويل الرقم [رقم الهاتف] بنجاح لنظام ريد (Enterprise member control) وهو جاهز للتفعيل الآن.
3. الفحص الدوري والجدولة:
   - تنفيذ فحص دوري للأرقام في تبويب قيد المراقبة وفقاً للفترة الزمنية المحددة في لوحة الإدارة.
   - تحديث تاريخ ووقت آخر فحص مع كل عملية تحقق ناجحة.
4. الصلاحيات الافتراضية:
   - ميزة VIP تكون مفعّلة افتراضياً للأدمن فقط، ومغلقة لباقي المستخدمين حتى يتم منح الصلاحية فردياً أو جماعياً.

| إدخال رقم هاتف بتنسيق غير صحيح | عرض تنبيه يوضح الخطأ ومنع إضافة الرقم غير المطابق |

| رقم بنظام فليكس أو نظام غير مؤهل | إدراج الرقم في تبويب غير مؤهل وتوجيه المستخدم لتغيير النظام إلى 14 قرش |

## 6. معايير القبول

1. يستطيع الأدمن تفعيل الميزة لجميع المستخدمين أو تخصيصها لمستخدمين محددين وتعديل دورية الفحص من لوحة الإدارة.
2. يظهر قسم VIP لمراقبة تحويلات خطوط ريد داخل صفحة معلومات الخط للمستخدمين المصرّح لهم فقط.
3. يتيح النظام إضافة رقم فردي أو مجموعة أرقام دفعة واحدة مع إجراء فحص فوري لتحديد نظام كل رقم.
4. يتم تصنيف الأرقام بدقة في التبويبات الثلاثة (قيد المراقبة، تم التحويل بنجاح، غير مؤهل) حسب نظام الخط.
5. عند تحول أي رقم إلى Enterprise member control يتم نقله فوراً لقائمة المحولة بنجاح وإرسال إشعار فوري للمستخدم.
6. يعرض زر تفاصيل الخط نافذة منبثقة تحتوي على كامل بيانات الخط المفحوص.
7. يعمل زر فحص الآن وزر فحص جميع الأرقام الآن على تحديث الحالات فورياً دون أخطاء.
8. حذف الرقم من المراقبة يزيله بشكل نهائي من القوائم ومهام الفحص الدوري.
