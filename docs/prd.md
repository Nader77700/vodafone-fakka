# وثيقة المتطلبات

## 1. نظرة عامة على التطبيق

### 1.1 اسم التطبيق
Vodafone Fakka Premium

### 1.2 المالك
Nader Akram

### 1.3 الإصدار
v3.0.38

### 1.4 الوصف
منصة ويب احترافية لشحن كروت الفكة مع نظام اشتراكات وأكواد ترخيص، مصممة بواجهة عربية فاخرة وتدعم التكامل المستقبلي مع محرك شحن خارجي. تتضمن مركز شبكات متعدد لعرض خدمات Vodafone وOrange وEtisalat وWE، مع نظام إدارة كروت ديناميكي كامل وتحسينات أداء شاملة. تشمل المرحلة الجديدة إعادة بناء لوحة الإدارة بالكامل بصفحات كاملة احترافية، بالإضافة إلى نظام تقييم الكروت واقتراح التعديلات، ونظام وضع المعاينة Preview Mode، وإعادة بناء قسم عروض واشتراكات فودافون بالكامل، وتحسينات شاملة لقسم خدمات الخطوط والمحافظ (My NTRA) في PHASE 3.

### 1.5 المبادئ الأساسية
- جميع البيانات ديناميكية (الكروت، الأسعار، الوحدات، الحالات)
- لا توجد بيانات ثابتة أو افتراضية
- النظام جاهز للربط مع API خارجي أو Recharge Engine
- تصميم Premium حديث بنمط Dark Luxury UI
- دعم كامل للغة العربية RTL
- Mobile First و Responsive
- Offline-First مع مزامنة ذكية
- منع التكرار في جميع العمليات
- لوحة إدارة احترافية بصفحات كاملة بدون Popup/Modal
- حماية Server-Side لجميع الصلاحيات والاشتراكات
- عدم تخزين passwords أو OTP أو tokens في logs أو frontend

### 1.6 الألوان
- Background: #0B0B14
- Primary: #E60000
- Secondary: #FFFFFF
- Accent: #FF3B3B
- Cards: #151523
- Borders: rgba(255,255,255,0.08)

### 1.7 خصائص التصميم
- Glassmorphism خفيف
- Shadows احترافية
- Animations ناعمة وسريعة
- Glow Effects و Border Animations
- Smooth Transitions
- Skeleton Loading
- Sticky Header و Sticky Action Bar

## 2. المستخدمون وسيناريوهات الاستخدام

### 2.1 المستخدمون المستهدفون
- المستخدمون النهائيون: أفراد يحتاجون لشحن كروت الفكة واستعراض خدمات الشبكات والاشتراك في عروض فودافون والاستعلام عن خطوطهم ومحافظهم عبر My NTRA
- مستخدمو المعاينة Preview Users: أفراد يريدون تجربة التطبيق قبل الاشتراك
- المسؤولون (Admin): إدارة المستخدمين والاشتراكات والأكواد والكروت والإصدارات والميزات ووضع المعاينة
- المسؤولون الرئيسيون (Super Admin): صلاحيات كاملة على النظام

### 2.2 السيناريوهات الأساسية
- تفعيل الاشتراك باستخدام كود تفعيل
- الدخول إلى وضع المعاينة Preview Mode لتجربة التطبيق
- شحن كروت الفكة بشكل متكرر
- استعراض خدمات الشبكات المختلفة
- استعراض عروض فودافون والاشتراك فيها
- إدارة الاشتراكات القادمة
- شحن الرصيد من قسم عروض فودافون
- حفظ الأرقام المفضلة للشحن السريع
- مراجعة سجل العمليات السابقة
- مراجعة الإحصائيات التفصيلية
- تقييم الكروت واقتراح تعديلات على بياناتها
- الاستعلام عن الخطوط والمحافظ المسجلة باسم المستخدم عبر My NTRA الرسمي
- إدارة الاشتراكات والأكواد والكروت (للمسؤولين)
- إدارة الأصول المرئية الديناميكية (للمسؤولين)
- حذف المستخدمين نهائياً (للمسؤولين)
- مراقبة المستخدمين والإصدارات في الوقت الفعلي (للمسؤولين)
- إدارة الميزات والإصدارات بدون تحديث APK (للمسؤولين)
- تنفيذ إجراءات متقدمة على حسابات المستخدمين (للمسؤولين)
- مراجعة تقييمات واقتراحات المستخدمين على الكروت (للمسؤولين)
- إدارة وضع المعاينة Preview Mode (للمسؤولين)

### 3.2 قسم عروض واشتراكات فودافون (محدث)

#### 3.2.1 الصفحة الرئيسية للقسم

##### الوظيفة
- عرض بطاقة عروض واشتراكات فودافون في أعلى الصفحة تحتوي على:
  - أيقونة فودافون
  - عنوان: عروض واشتراكات فودافون
  - وصف مختصر: إدارة اشتراكاتك واستعراض العروض المتاحة
- عرض بطاقة سجّل دخولك تحتوي على:
  - أيقونة تسجيل الدخول
  - نص: سجّل دخولك لعرض اشتراكاتك والعروض المتاحة
  - زر تسجيل الدخول
- التصميم: Dark Premium UI، RTL، Mobile First، بدون Horizontal Overflow
- زر العودة للصفحة السابقة
- لا يتم عرض الاشتراكات أو العروض قبل تسجيل الدخول

#### 3.2.2 صفحة تسجيل الدخول

##### الوظيفة
- Header: عنوان تسجيل الدخول، زر العودة
- حقول الإدخال:
  - رقم الهاتف
  - كلمة المرور
- زر تسجيل الدخول
- عند نجاح تسجيل الدخول:
  - حفظ بيانات المستخدم في localStorage
  - الانتقال إلى صفحة الاشتراكات القادمة
  - عرض رقم الهاتف المسجل بشكل صحيح ومنسق
- عند فشل تسجيل الدخول:
  - عرض رسالة خطأ واضحة
  - إبقاء المستخدم في صفحة تسجيل الدخول
- Loading State أثناء تسجيل الدخول
- الربط بالسكريبت الحالي لتسجيل الدخول

#### 3.2.3 صفحة الاشتراكات القادمة

##### الوظيفة
- Header: عنوان الاشتراكات القادمة، زر العودة
- عرض رقم الهاتف المسجل بشكل صحيح ومنسق
- عرض قسم الاشتراكات القادمة في تصميم Compact:
  - كل اشتراك في صف أو كارت صغير يحتوي على:
    - اسم الباقة
    - السعر
    - النوع
    - الحالة
    - زر إلغاء الاشتراك (صغير ومنظم بجانب معلومات الباقة)
    - زر شحن (إذا كان متاحاً للباقة)
- عرض جميع حالات الاشتراكات:
  - الاشتراكات القادمة
  - الباقات المفعلة
  - الباقات غير المفعلة
- التحديث التلقائي للاشتراكات عند التحديث/إعادة الجلب
- عرض اختصار شحن الرصيد العام أسفل الاشتراكات
- عرض أقسام العروض:
  - بطاقة عروض فليكس
  - بطاقة عروض باقات الإنترنت
  - بطاقة عروض أخرى
- كل بطاقة عروض تحتوي على:
  - أيقونة
  - عنوان
  - وصف مختصر
  - زر الدخول
- Loading State أثناء تحميل البيانات
- رسالة لا توجد اشتراكات متاحة حالياً إذا كانت القائمة فارغة
- الربط بالسكريبت الحالي لجلب الاشتراكات

### 3.3 قسم خدمات الخطوط والمحافظ (My NTRA) - PHASE 3 (محدث)

#### 3.3.1 الصفحة الرئيسية للقسم

##### الوظيفة
- عرض بطاقة توضيحية في أعلى الصفحة تحتوي على:
  - أيقونة معلومات واضحة
  - عنوان: خدمة الاستعلام عن الخطوط والمحافظ
  - نص توضيحي: هذه الخدمة مخصصة للاستعلام عن بيانات الخطوط والمحافظ المسجلة باسمك عبر My NTRA الرسمي (الجهاز القومي لتنظيم الاتصالات في مصر)
- عرض بطاقات قصيرة ومضغوطة تحتوي على:
  - بطاقة تسجيل الدخول: أيقونة، عنوان، وصف مختصر، زر الدخول
  - بطاقة إنشاء حساب جديد: أيقونة، عنوان، وصف مختصر، زر إنشاء
- التصميم: Dark Premium UI، RTL، Mobile First، بدون Horizontal Overflow
- زر العودة للصفحة الرئيسية
- لا يتطلب اشتراكاً نشطاً للوصول إلى هذا القسم (خدمة مجانية)

#### 3.3.2 صفحة تسجيل الدخول (محدثة)

##### الوظيفة
- Header: عنوان تسجيل الدخول إلى My NTRA، زر العودة
- عرض وصف واضح: سجّل الدخول باستخدام حسابك الرسمي على My NTRA للوصول إلى بيانات الخطوط والمحافظ المسجلة باسمك
- حقول الإدخال:
  - رقم الهاتف (يظهر بترتيب LTR صحيح)
  - كلمة المرور (مع Masking)
- زر تسجيل الدخول
- عرض توضيح أسفل النموذج: ليس لديك حساب على My NTRA؟ يمكنك إنشاء حساب جديد من هنا
- زر إنشاء حساب مميز (بتصميم Secondary Button)
- عند نجاح تسجيل الدخول:
  - حفظ loginToken و username و email القادمين من My NTRA في localStorage
  - الانتقال إلى صفحة التحقق من الرقم القومي
- عند فشل تسجيل الدخول:
  - عرض رسالة خطأ واضحة داخل نفس الصفحة (مثل: بيانات الدخول غير صحيحة)
  - عدم إعادة المستخدم إلى Home
  - إبقاء المستخدم في صفحة تسجيل الدخول مع إمكانية إعادة المحاولة
- Loading State أثناء تسجيل الدخول مع تعطيل زر الدخول مؤقتاً
- الربط بـ API الموجود في السكريبت `/workspace/app-ck2v94t1nev5/tasks/my_ntra_password_tool.py`

#### 3.3.3 صفحة إنشاء الحساب (محدثة)

##### الوظيفة
- Header: عنوان إنشاء حساب My NTRA جديد، زر العودة
- عرض وصف واضح: أنشئ حسابك الرسمي على My NTRA للوصول إلى بيانات الخطوط والمحافظ المسجلة باسمك. هذا الحساب هو حساب My NTRA الرسمي وليس خاصاً بالتطبيق.
- حقول الإدخال:
  - الاسم الكامل
  - البريد الإلكتروني
  - رقم الهاتف (يظهر بترتيب LTR صحيح)
  - كلمة المرور (مع Masking)
  - تأكيد كلمة المرور (مع Masking)
- زر إنشاء الحساب
- عند نجاح إنشاء الحساب:
  - حفظ loginToken و username و email في localStorage
  - الانتقال إلى صفحة التحقق من الرقم القومي
- عند فشل إنشاء الحساب:
  - عرض رسالة خطأ واضحة داخل نفس الصفحة
  - عدم إعادة المستخدم إلى Home
  - إبقاء المستخدم في صفحة إنشاء الحساب مع إمكانية إعادة المحاولة
- Loading State أثناء إنشاء الحساب مع تعطيل زر الإنشاء مؤقتاً
- الربط بـ API الموجود في السكريبت

#### 3.3.4 صفحة التحقق من الرقم القومي (محدثة)

##### الوظيفة
- Header: عنوان التحقق من الرقم القومي، زر العودة
- عرض اسم المستخدم (username) والبريد الإلكتروني (email) الحقيقيين القادمين من My NTRA
- عرض نص توضيحي: للتأكد من ارتباط الرقم القومي بحسابك قبل إظهار البيانات الكاملة، يرجى إدخال الرقم القومي المكون من 14 رقماً
- حقل إدخال الرقم القومي:
  - يقبل 14 رقماً فقط
  - Validation قبل إرسال الطلب (عرض رسالة خطأ إذا كان الرقم أقل أو أكثر من 14 رقماً)
- زر التحقق
- عند نجاح التحقق (code=200):
  - عرض رسالة نجاح واضحة: تم التحقق من الرقم القومي بنجاح
  - حفظ nationalId في localStorage
  - الانتقال إلى صفحة النتائج
- عند عدم التطابق (code=34012):
  - عرض errorMsg الفعلي القادم من API داخل نفس الصفحة
  - عدم إعادة المستخدم إلى Home أو صفحة تسجيل الدخول
  - إبقاء المستخدم في صفحة التحقق مع إمكانية إعادة المحاولة
- عند حدوث HTTP Error أو Server Error:
  - عرض رسالة خطأ واضحة داخل نفس الصفحة (مثل: حدث خطأ في الاتصال، يرجى المحاولة لاحقاً)
  - عدم إعادة المستخدم إلى Home
  - إبقاء المستخدم في صفحة التحقق مع زر إعادة المحاولة
- Loading State أثناء التحقق مع نص: جاري التحقق من الرقم القومي...
- تعطيل زر التحقق مؤقتاً أثناء الطلب لمنع Requests متكررة
- الربط بـ API التحقق الموجود في السكريبت مع استخدام loginToken

#### 3.3.5 صفحة النتائج (محدثة)

##### الوظيفة
- Header: عنوان بيانات الخطوط والمحافظ على My NTRA، زر العودة
- عرض بيانات حساب المستخدم:
  - الاسم الحقيقي (username) القادم من My NTRA
  - البريد الإلكتروني (email) القادم من My NTRA
- عرض إحصائيات:
  - عدد المحافظ المسجلة
  - عدد الخطوط المسجلة
- عرض قائمة المحافظ:
  - كل محفظة في Card مضغوط
  - عرض رقم المحفظة مع Masking (عرض آخر 4 أرقام فقط، مثل: ****3680)
- عرض قائمة الخطوط:
  - كل خط في Card مضغوط
  - عرض رقم الخط مع Masking (عرض آخر 4 أرقام فقط، مثل: ****3680)
- عرض Card Premium صغير ومنظم لإظهار الأرقام كاملة:
  - أيقونة قفل أو تحقق
  - عنوان: إظهار الأرقام كاملة
  - نص توضيحي مختصر: للتأكد من هويتك قبل إظهار الأرقام الكاملة، يتطلب تحقق OTP
  - زر إظهار الأرقام كاملة
- زر تسجيل الخروج

| الضغط المتكرر على زر التحقق | تعطيل الزر مؤقتاً أثناء الطلب |
